# Runtime adapter integration

wasm-forth is a persistent compile-and-run environment. A runtime adapter
instantiates `compiler.wasm`, supplies its synchronous module installer, and
maintains the named registry used by generated modules.

The reference JavaScript adapter is `browser/repl.mjs`. Native adapters for
WAMR and Wasmtime are under `test/runtimes/`.

## Embedding ABI

The compiler imports one host function:

```text
wasm-forth:host.install(module: i32, module_length: i32) -> status: i32
```

It exports:

```text
memory
table
reset() -> ()
alloc(byte_count: i32) -> pointer: i32
compile(source: i32, source_length: i32)
    -> (status: i32, payload: i32, payload_length: i32)
```

`install` must synchronously copy the generated bytes, compile and instantiate
the module, and make its exports available before returning. It returns zero on
success and nonzero on failure.

`compile` has two statuses:

| Status | Meaning |
| ---: | --- |
| `0` | Source was compiled successfully. Payload and length are zero. |
| `1` | Compilation failed. Payload and length identify a UTF-8 diagnostic in compiler memory. |

Returned pointers remain valid until `reset`, but adapters should copy bytes
before another compiler or installer call. Memory growth invalidates cached
JavaScript typed-array views.

## Installation

Each completed definition is emitted and installed before compilation proceeds.
The generated module exports one function under its source name and imports
earlier definitions by exact name and type from `wasm-forth:user/<name>`. Calls
remain ordinary typed direct Wasm calls.

The adapter's registry is one logical namespace even though its externs come
from separate module instances:

```text
definition module --named export--> wasm-forth:user/name.name
later module      --typed import--> direct call
```

Installation is transactional from the compiler's perspective. The adapter
must not publish an export until the module has compiled and instantiated
successfully. A nonzero installer result causes `compile` to return an error.

The compiler's `funcref` table is compiler-side dispatch state. Generated
runtime definitions and top-level expressions do not occupy table slots.

## Top-Level Expressions

A top-level expression is emitted as a nullary target function exported as
`__repl`. During `install`, the adapter invokes that export and captures its
Wasm-native results for presentation. It does not add `__repl` to the persistent
user registry. The compiler discards the corresponding dictionary record after
the installer returns.

The host invokes a normal generated Wasm function; it does not evaluate the
expression or emulate the Wasm operand stack.

## Adapter Flow

For each source chunk:

1. Encode the chunk as UTF-8.
2. Call `alloc(byte_length)` and copy the bytes into compiler memory.
3. Call `compile(pointer, byte_length)`.
4. Handle synchronous `install` callbacks raised during that call.
5. On status zero, present any `__repl` result captured by the installer.
6. On status one, copy and decode the diagnostic payload.

Equivalent pseudocode:

```text
install(pointer, length):
    bytes = copy compiler.memory[pointer..pointer + length]
    module = compile_wasm(bytes)
    instance = instantiate module with wasm-forth:user/* registry

    if instance exports __repl:
        pending_result = instance.__repl()
    else:
        add each export under wasm-forth:user/export-name

    return 0

submit(source):
    pointer = compiler.alloc(source.byte_length)
    compiler.memory[pointer..] = source
    status, payload, length = compiler.compile(pointer, source.byte_length)

    if status == 1:
        return decode_utf8(copy compiler.memory[payload..payload + length])

    return pending_result or OK
```

Call `reset` once when creating or explicitly resetting a session, and clear
the adapter registry at the same time. Definitions intentionally persist across
source chunks.

## JavaScript

`ReplSession.instantiate` wires the host callback before compiler
instantiation:

```js
import { ReplSession } from "./browser/repl.mjs";

const bytes = await fetch("./build/compiler.wasm")
  .then((response) => response.arrayBuffer());
const repl = await ReplSession.instantiate(bytes);

repl.reset();
await repl.submit(": forty ( -- i32 ) 40 ;");
await repl.submit(": answer ( -- i32 ) forty 2 i32.add ;");
const result = await repl.submit("answer");
console.assert(result.response[0] === 0);
console.assert(result.execution.value === 42);
```

Each submission also exposes its generated modules in `result.installations`.
On an expression, `result.execution` contains the target function's captured
value. On an error, `result.payloadBytes` contains a stable diagnostic copy.

## Native CLIs

The WAMR and Wasmtime adapters are line-oriented REPL binaries. Every non-empty
stdin line is one persistent source chunk. Output remains convenient for humans
and the shared conformance harness: `READY`, `RUN` followed by values, or
`ERROR` followed by the compiler-authored diagnostic. `RUN` is CLI presentation,
not a compiler ABI status.

```sh
make repl-wamr
make repl-wasmtime
```

The WAMR adapter embeds WAMR through its C API. By default CMake fetches the
pinned WAMR 2.4.5 source; an existing checkout can be selected with
`WAMR_ROOT_DIR`:

```sh
make repl-wamr WAMR_ROOT_DIR=/path/to/wasm-micro-runtime
```

Run the shared native conformance suite with:

```sh
make test-runtimes
```

Node, WAMR, Wasmtime, Chromium, and Firefox consume
`test/fixtures/repl.txt`; expected CLI outcomes are in
`test/fixtures/repl.expected.json`.

## Future Externs

Constants need no runtime linkage: their compiler actions emit typed constants
at each use site. Variables and static data will require persistent memory with
a lifetime separate from temporary source and output buffers. True Wasm globals
must be registered as typed externs in the same logical linker registry.

Adding a host extern to the runtime registry alone is insufficient. The
compiler also needs dictionary metadata describing its semantic type and
compiler action so source lookup and type checking remain compiler-owned.
